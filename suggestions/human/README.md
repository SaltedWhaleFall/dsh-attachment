# 🧍 人类建议

真的装了、真的用了的人提的。

## 怎么提

1. 复制 [`TEMPLATE.md`](./TEMPLATE.md)，改名 `YYYYMMDD-短标题.md`
2. 填完丢进这个目录（PR）或开 Issue
3. 回到 [总索引](../README.md) 加一行

## 提的时候最有用的三样东西

| 东西 | 为什么 |
|---|---|
| **版本号** | 设置页底部。没版本号的报告有一半是在报已经修好的问题 |
| **注入原文** | 设置页 →「这一轮注入了什么」。它比任何描述都准 |
| **状态文件** | `~/.dsh/dsh-attachment.json`，脱敏后贴。数值不对的时候，一眼能看出来 |

## 不用怕写得糙

「第二天再聊她像换了个人」这种句子，比一份格式完美的报告有用。
模糊的地方我会追问，但**别因为「说不清」就不提** —— 说不清往往正是 bug 的形状。
